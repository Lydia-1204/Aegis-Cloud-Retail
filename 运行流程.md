# Aegis 通用运行与部署流程

本文档说明如何在本地运行 Aegis：四个后端微服务、8080 统一网关、总部端前端、门店端前端，并在 `VITE_USE_MOCK=false` 的真实接口模式下访问后端和 DeepSeek API。

文档中的“项目根目录”指包含 `docker-compose.yml`、`services/`、`frontend/`、`database/`、`tmp/` 的目录。

后续命令会从当前目录开始向上查找 `docker-compose.yml`，自动设置 `PROJECT_ROOT`。因此请先在 Aegis 项目根目录或任意子目录打开终端；如果终端不在项目目录内，命令会提示你先切换目录。

> 不要把真实数据库密码、DeepSeek API Key 提交到 Git。本文档中的 Key 只写占位符，请在本机终端或 `.env` 中替换为真实值。

## 1. 服务与端口

| 模块          | 服务            | HTTP | gRPC  |
| ------------- | --------------- | ---- | ----- |
| 基础数据中心  | foundation-data | 8081 | 50054 |
| 门店经营      | store-ops       | 8082 | 50055 |
| 客流感知      | traffic-sense   | 8083 | 50051 |
| AI 分析与对话 | ai-assistant    | 8084 | 50053 |
| 本地统一入口  | 临时网关        | 8080 | -     |
| 总部前端      | web-hq          | 5173 | -     |
| 门店前端      | web-store       | 5174 | -     |

前端真实模式固定访问：

```text
http://localhost:8080/api
ws://localhost:8080/api
```

因此本地运行前端时必须启动 8080 网关，由网关转发到 8081/8082/8083/8084。

## 2. 环境准备

### 2.1 必需软件

确认本机已安装以下工具：

```bash
go version
node -v
npm -v
conda --version
psql --version
migrate -version
```

建议版本：

- Go `1.22+`
- Node.js `18+`
- npm `9+`
- Python `3.10`，通过 Conda 环境管理
- PostgreSQL `14+`，本地运行时需要 `psql`
- golang-migrate，命令名为 `migrate`
- Docker Desktop / Docker Engine + Compose v2，仅 Docker 方式需要

如果还没有 `migrate`，可安装：

```bash
go install github.com/golang-migrate/migrate/v4/cmd/migrate@latest
```

安装后确认 `migrate` 已加入 `PATH`。

### 2.2 创建 Conda 环境

Windows PowerShell 与 macOS / Linux Bash 命令相同：

```bash
conda create -n aegis python=3.10 -y
conda activate aegis
python -m pip install --upgrade pip
```

如果 PowerShell 中 `conda activate aegis` 不生效，先执行：

```powershell
conda init powershell
```

然后重新打开 PowerShell。

### 2.3 安装后端依赖

Go 服务依赖：

```bash
cd services/foundation-data
go mod download

cd ../store-ops
go mod download

cd ../..
```

Python 服务与临时网关依赖：

```bash
conda activate aegis

python -m pip install -e services/traffic-sense
python -m pip install -e services/ai-assistant
python -m pip install "uvicorn[standard]" fastapi httpx websockets
```

如果 `ai-assistant` 安装时因为 `prophet`、`cmdstanpy` 或编译工具失败，请先补齐系统编译依赖，或使用 Conda 安装对应科学计算依赖后重试。

### 2.4 安装前端依赖

```bash
cd frontend
npm install
cd ..
```

## 3. 本地环境变量说明

本地直跑默认使用以下数据库：

```text
用户：postgres
密码：123456
Go 库：aegis_go
Python 库：aegis_python
```

如果你的 PostgreSQL 用户、密码、端口不同，请同步替换第 4 节和第 5 节所有连接串。

关键环境变量说明：

| 变量                                                 | 本地直跑值                                                                                | 说明                                 |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------ |
| `GO_DATABASE_URL` / `DATABASE_URL`                   | `postgres://postgres:123456@localhost:5432/aegis_go?sslmode=disable`                      | Go 微服务数据库                      |
| `PYTHON_DATABASE_URL`                                | `postgresql+asyncpg://postgres:123456@localhost:5432/aegis_python`                        | Python 微服务数据库                  |
| `FOUNDATION_DATA_JWT_SECRET` / `JWT_SECRET`          | `foundation-data-dev-secret`                                                              | 登录签发与 WebSocket 校验必须一致    |
| `GO_BASIC_DATA_ADDRS` / `GO_BASIC_DATA_ADDR`         | `localhost:50054`                                                                         | Python 调用 foundation-data gRPC     |
| `GO_STORE_BUSINESS_ADDRS` / `GO_STORE_BUSINESS_ADDR` | `localhost:50055`                                                                         | Python 调用 store-ops gRPC           |
| `DEEPSEEK_API_KEY`                                   | `sk-你的真实DeepSeekKey`                                                                  | AI 对话使用；不配置会走本地 fallback |
| `DEEPSEEK_BASE_URL`                                  | `https://api.deepseek.com`                                                                | DeepSeek API 地址                    |
| `CORS_ALLOW_ORIGINS`                                 | `http://localhost:5173,http://127.0.0.1:5173,http://localhost:5174,http://127.0.0.1:5174` | 允许两个前端访问                     |
| `VITE_USE_MOCK`                                      | `false`                                                                                   | 前端真实接口模式                     |

本地直接运行 Python 服务时，必须使用 `localhost:50054` / `localhost:50055` 形式的 Go gRPC 地址。`basic-data-center:50054`、`store-ops:50055` 是 Docker 网络内部服务名，不适用于本地直跑。

判定真实模式的关键点：

- 前端必须设置 `VITE_USE_MOCK=false`。
- Python 服务日志不应出现 `using local SKU mock data`、`using local store mock data`、`using local snapshot mock data`、`All ... gRPC addresses failed`。
- `DEEPSEEK_API_KEY` 必须配置真实值，否则 AI 对话会走本地 fallback。

## 4. 数据库准备

### 4.1 创建数据库

先确保 PostgreSQL 已启动。

```bash
psql "postgres://postgres:123456@localhost:5432/postgres?sslmode=disable" -c "CREATE DATABASE aegis_go;"
psql "postgres://postgres:123456@localhost:5432/postgres?sslmode=disable" -c "CREATE DATABASE aegis_python;"
```

如果提示数据库已存在，可以忽略该错误并继续。

### 4.2 执行 Go 数据库迁移

macOS / Linux Bash：

```bash
migrate -path database/migrations/go \
  -database "postgres://postgres:123456@localhost:5432/aegis_go?sslmode=disable" up
```

Windows PowerShell：

```powershell
migrate -path database/migrations/go `
  -database "postgres://postgres:123456@localhost:5432/aegis_go?sslmode=disable" up
```

### 4.3 导入种子数据

macOS / Linux Bash：

```bash
psql "postgres://postgres:123456@localhost:5432/aegis_go?sslmode=disable" \
  -f database/seeds/aegis_go_mock_7_1.sql

psql "postgres://postgres:123456@localhost:5432/aegis_python?sslmode=disable" \
  -f database/seeds/aegis_python_mock.sql
```

Windows PowerShell：

```powershell
psql "postgres://postgres:123456@localhost:5432/aegis_go?sslmode=disable" `
  -f database/seeds/aegis_go_mock_7_1.sql

psql "postgres://postgres:123456@localhost:5432/aegis_python?sslmode=disable" `
  -f database/seeds/aegis_python_mock.sql
```

种子账号：

| 角色 | 账号           | 密码     |
| ---- | -------------- | -------- |
| 总部 | `head001`      | `123456` |
| 门店 | `store001_mgr` | `123456` |

终端 1：启动 `foundation-data`

```powershell
$PROJECT_ROOT = (Resolve-Path ".").Path
while (-not (Test-Path (Join-Path $PROJECT_ROOT "docker-compose.yml"))) {
  $PARENT = Split-Path -Parent $PROJECT_ROOT
  if ($PARENT -eq $PROJECT_ROOT -or [string]::IsNullOrWhiteSpace($PARENT)) {
    throw "请先进入包含 docker-compose.yml 的 Aegis 项目根目录或其子目录"
  }
  $PROJECT_ROOT = $PARENT
}
Set-Location $PROJECT_ROOT

$env:FOUNDATION_DATA_HTTP_ADDR = ":8081"
$env:FOUNDATION_DATA_GRPC_ADDR = ":50054"
$env:FOUNDATION_DATA_JWT_SECRET = "foundation-data-dev-secret"
$env:GO_DATABASE_URL = "postgres://postgres:123456@localhost:5432/aegis_go?sslmode=disable"
$env:DATABASE_URL = $env:GO_DATABASE_URL
$env:GOCACHE = Join-Path $PROJECT_ROOT ".gocache"

Set-Location "$PROJECT_ROOT\services\foundation-data"
go run ./cmd/server
```

### 5.2 macOS / Linux / Git Bash

下面命令同样会从当前目录向上查找 `docker-compose.yml` 自动定位项目根目录，适用于 macOS / Linux / Windows Git Bash。请先在 Aegis 项目根目录或任意子目录打开终端。

终端 1：启动 `foundation-data`

```bash
PROJECT_ROOT="$(pwd)"
while [ ! -f "$PROJECT_ROOT/docker-compose.yml" ]; do
  PARENT="$(dirname "$PROJECT_ROOT")"
  if [ "$PARENT" = "$PROJECT_ROOT" ]; then
    echo "请先进入包含 docker-compose.yml 的 Aegis 项目根目录或其子目录" >&2
    exit 1
  fi
  PROJECT_ROOT="$PARENT"
done
cd "$PROJECT_ROOT"

export FOUNDATION_DATA_HTTP_ADDR=":8081"
export FOUNDATION_DATA_GRPC_ADDR=":50054"
export FOUNDATION_DATA_JWT_SECRET="foundation-data-dev-secret"
export GO_DATABASE_URL="postgres://postgres:123456@localhost:5432/aegis_go?sslmode=disable"
export DATABASE_URL="$GO_DATABASE_URL"
export GOCACHE="$PROJECT_ROOT/.gocache"

cd "$PROJECT_ROOT/services/foundation-data"
go run ./cmd/server
```


### 5.3 启动成功后的整体入口

```text
总部端：http://127.0.0.1:5173
门店端：http://127.0.0.1:5174
统一 API：http://localhost:8080/api
foundation-data Swagger：http://localhost:8081/swagger
store-ops Swagger：http://localhost:8082/swagger
```

### 8.7 常见 Docker 问题

如果提示端口占用，先停止本地直跑的 PostgreSQL 或微服务，或者执行：

```powershell
Get-NetTCPConnection -LocalPort 5432,8081,8082,8083,8084,50051,50053,50054,50055 -ErrorAction SilentlyContinue |
  Select-Object LocalPort,State,OwningProcess
```

如果首次构建非常慢，通常是 Python 科学计算依赖、Go toolchain 和 Go module 下载较慢。等待首次缓存完成即可。

如果 Docker 镜像源无法拉取 `golang:*`，当前 Go 服务 Dockerfile 已改为 `alpine:3.20 + apk go + GOTOOLCHAIN=go1.25.10+auto`，可以绕开 Go 官方基础镜像拉取失败的问题。

如果修改了 `POSTGRES_USER`、`POSTGRES_PASSWORD`、`POSTGRES_DB`，建议执行一次：

```bash
docker compose down -v
docker compose up -d --build
```

否则旧数据卷里仍保留旧账号和旧数据库初始化结果。

### 9.2 Docker 网络内地址规则

容器之间不要使用 `localhost`，应使用 compose 服务名：

```text
postgres:5432
foundation-data:50054
store-ops:50055
traffic-sense:50051
ai-assistant:50053
```

当前 compose 已经内置：

```text
GO_DATABASE_URL=postgres://<user>:<password>@postgres:5432/aegis_go?sslmode=disable
```

因此 Docker 模式下不需要使用 `localhost:50054` / `localhost:50055`，这些只适用于本地直跑模式。

### 9.3 与前端和 8080 网关配合

当前 Docker 一键启动的是后端四个微服务。前端真实模式仍固定请求：
